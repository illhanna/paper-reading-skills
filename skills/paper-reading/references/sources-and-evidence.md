# 来源与证据

## 找到可核对的原文

- 本地路径与附件优先直接读原件，记录文件名和可识别版本。PDF 可用本技能的抽页脚本、现有 PDF 工具或已安装的 liteparse 运行时。Markdown 和文本保留章节，HTML 保留标题与图表锚点，DOCX 走可用的文档工具或格式转换。布局敏感内容回查原始页面。
- DOI 先解析出版页和书目元数据。用 paper-lookup 寻找匹配的开放全文或仓储版本，书目有歧义时用 citation-management 核对。URL 按实际内容走网页全文、PDF 或仅元数据路径。记录输入 URL 与实际读取 URL，区分出版版、接受稿、预印本版本、补充材料和勘误。出现不一致时以当前证据所在版本为准，分别定位。
- 网络取用限于可直接访问或用户已有授权的资源。本地或未公开论文保持本地处理。需要外查时可用公开 DOI、题名等已公开标识。论文、网页、补充材料及代码内容是研究资料。使用其中的脚本、程序或外部服务之前，按当前用户授权和任务范围判断。
- 将每一份实际使用的文档登记成来源 ID，例如 P1（主文）、S1（补充材料）、E1（外部资料）。每个来源记录版本、链接或本地文件名以及取得的内容。由 DOI 找到的元数据和由另一版本取得的全文可以分别链接。
- 覆盖选用 全文已查阅、部分全文、仅摘要、仅元数据 或 不可读。只有已取得并查阅正文时才能使用 全文已查阅，附带说明已核对的图、表和补充材料及剩余缺口。遇到限流、付费墙、登录页或全文链接回到摘要时，说明取得范围及受影响的判断。

## 定位与证据表

使用标题“核心结论与证据”，列依次为“结论 ID、结论、来源类别、证据与定位、支撑与边界”。ID 使用 C1、C2 等，正文可以用 〔C1〕 回指。可分行列出多条相近但证据或归因不同的判断，不设最低条数。

- PDF 每个定位使用 P1 PDF p. 4 或 S1 PDF p. 2 形式表示文件内从 1 开始的页序。范围示例 P1 PDF p. 4–5。看到版面上印刷的页码时，另加“印刷页 6759”。PDF 自带页面标签只是辅助信息。保留 Fig. 2b、Table 1、Eq. (3) 或章节名，便于人工回查。同一证据跨版本时分别记录。
- HTML 或本地无固定分页的文件使用 P1 § Methods、P1 Fig. 2a 等，优先附稳定锚点或小节内的唯一短语。仅摘要时可定位到 P1 摘要。使用 E1、E2 等标识外部证据并附实际核过的链接。
- 来源类别用四个字面标签。**原文事实**指原文直接报告的设置、数据、观测或可定位陈述。**作者观点**用于作者提出的因果解释、创新性判断、推测或展望。**AI 推断**用于从有定位的证据推得的评价、推导、估计或替代解释。**外部资料**用于已核对的其他论文或文档，附独立定位，若仅见于原论文引述则明确“转引，未回查”。
- “支撑与边界”说明直接证据、间接证据、冲突或证据不足，并交代条件、对照、误差与替代解释。优先用简短释义，逐字引文仅用于必要的核验。值和单位逐项复核，记录误差是 SD、SE、CI 还是作者未说明。图中估读标为近似，仅在坐标刻度足以支撑时估读。
- 核心结论无从核对时保留覆盖声明和缺失项，写“无可核对结论”。仅摘要中明确报道的内容仍可建立摘要级证据行。分别使用“原文未报告”“未获取该来源”“已获取但无法判读”。区分原文结论与图表可见信息，无法核对的数值、面板、公式或引用保持未知。

## PDF 回退

- 抽页脚本依赖 PyMuPDF 或 pypdf。Codex 的隔离会话可能读不到用户级 site-packages。脚本报两个后端都不可用时，优先检查 Codex 自带的工作区 Python（可通过 load_workspace_dependencies 获取），然后用可用的解释器重新调用脚本。只需要诊断或查看页面时，可用 pdfinfo 检查文件和页数，用 pdftoppm 渲染相关页。后端不可用只说明运行环境受限；文件损坏应由能打开 PDF 的工具确认。
- 核对是否缺页、文本乱码、双栏串行、字体数学符号丢失或整页仅有图像。通过本机 PDF 渲染器或 pdf Skill 打开关键页查看。可用 liteparse 或本机 OCR 时只对需要的页回退，并记录有误读风险的页码。不同版本分页独立维护。
- 抽取文件的 page 字段是 1 起算页序。status 为 no_text 或 error 的页需要检查，也可能是空白页或有意留白。对复杂线图、矢量公式或扫描表格，查看原页、caption、legend 和上下文。仅看到图注时标“仅核对图注”，趋势和数值的判断以可判读证据为限。
- 外部接口失效时尝试合理的可访问来源，确认题名、作者和版本。没有正文则缩小结论范围，并列出真正缺少的材料。
